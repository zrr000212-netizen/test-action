# general-skills

通用技能集合 - DTSE通用工具技能

本仓库收集DTSE项目开发的各类通用工具技能。

## 已提交技能

| 技能名称 | 描述 | 版本 |
|----------|------|------|
| **gitcode-cli** | GitCode命令行工具 - 管理GitCode仓库、issues、PRs、releases等，从终端操作无需浏览器 | 0.7.4 |

## 使用方法

技能遵循OpenClaw技能标准格式，可以通过ClawHub安装或手动复制到skills目录使用。
